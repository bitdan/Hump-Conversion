# 前端微信登录功能集成说明

## 功能概述

已成功为前端应用集成了完整的微信登录功能，包括：

1. **微信网页授权登录** - 点击按钮跳转到微信授权页面
2. **微信扫码登录** - 生成二维码供用户扫码登录
3. **微信账号绑定** - 将微信账号与现有账号绑定
4. **微信快速注册** - 通过微信快速创建账号

## 已修改的文件

### 1. API接口层 (`src/api/auth.ts`)

- 添加了微信登录相关的TypeScript接口定义
- 新增了7个微信登录相关的API函数
- 包括获取登录URL、微信登录、绑定账号、二维码登录等

### 2. 认证逻辑层 (`src/composables/useAuth.ts`)

- 扩展了useAuth composable，添加了微信登录相关方法
- 实现了完整的微信登录流程处理
- 包括状态管理、错误处理和用户信息更新

### 3. 登录页面 (`src/views/auth/LoginView.vue`)

- 添加了微信登录按钮和扫码登录按钮
- 集成了微信回调处理逻辑
- 添加了微信账号绑定对话框
- 优化了UI布局和样式

### 4. 注册页面 (`src/views/auth/RegisterView.vue`)

- 添加了微信快速注册按钮
- 集成了微信回调处理逻辑
- 添加了微信账号绑定对话框
- 保持了与登录页面一致的UI风格

### 5. 二维码登录组件 (`src/components/auth/QRLoginDialog.vue`)

- 创建了独立的二维码登录对话框组件
- 实现了二维码生成和状态轮询
- 支持实时状态更新和用户交互
- 集成了账号绑定功能

## 功能特性

### 微信网页登录

- 点击"微信登录"按钮跳转到微信授权页面
- 支持微信回调处理和自动登录
- 自动处理账号绑定流程

### 扫码登录

- 生成唯一的二维码供用户扫描
- 实时轮询登录状态（等待、已扫描、已确认、已过期）
- 支持状态可视化和用户反馈
- 自动处理登录成功和账号绑定

### 账号绑定

- 当微信账号未绑定现有账号时，自动弹出绑定对话框
- 支持输入用户名和密码进行绑定
- 绑定成功后自动登录并跳转

### 快速注册

- 通过微信快速创建新账号
- 自动获取微信用户信息
- 简化注册流程

## 使用流程

### 1. 微信网页登录

```
用户点击微信登录 → 跳转微信授权 → 微信回调 → 自动登录/绑定账号
```

### 2. 扫码登录

```
用户点击扫码登录 → 生成二维码 → 微信扫码 → 确认登录 → 自动登录/绑定账号
```

### 3. 账号绑定

```
微信登录检测到未绑定 → 弹出绑定对话框 → 输入账号信息 → 绑定成功 → 自动登录
```

## 配置要求

### 环境变量

确保后端已配置以下环境变量：

- `WECHAT_APP_ID` - 微信AppID
- `WECHAT_APP_SECRET` - 微信AppSecret
- `WECHAT_REDIRECT_URI` - 微信回调地址
- `FRONTEND_DOMAIN` - 前端域名

### 路由配置

确保前端路由支持微信回调：

```typescript
// 在路由中添加微信回调处理
{
  path: '/auth/login',
  name: 'Login',
  component: () => import('@/views/auth/LoginView.vue'),
  // 支持查询参数处理微信回调
}
```
